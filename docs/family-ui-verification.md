# 1Agent 家族视觉统一验收

## 实现

- 以 1Panel 的语义色为基准，在 `Theme.swift` 中保存原生浅深色常量；没有跨仓库运行依赖，没有修改 1Panel。
- `WindowChrome` 不再读取终端主题。侧栏实色、浅蓝选中底、品牌蓝文字；统一字体层级、控件状态、焦点环和圆角，设置改为平整分节。
- `AppearanceDriver.interfaceIsDark` 仅取决于应用外观；`terminalIsDark` 在预览时采用主题明暗。原生终端视图更新颜色，不因换色重建。
- 移除玻璃侧栏入口及材质切换；旧 `sidebar.material` 不再参与显示，也不删除该偏好。
- 保留官方终端主题、浅深双槽、预览事务、原有导航和工作区状态。顺带修复侧栏齿轮没有打开设置窗口的问题。

## 安装与界面检查

- `make build` 编译并安装到 `/Applications/1Agent.app`，检查正在运行的进程及构建/安装主代码哈希。
- 实机检查浅深两套文件双栏、设置、终端和已有五分屏；检查主机选择弹窗、选中和禁用状态、搜索键盘焦点环。
- 浅色界面预览 Dracula、深色界面预览 GitHub Light Colorblind：设置保持应用配色；取消或关闭设置恢复已保存主题。
- 验收结束恢复原有浅色模式、远程会话选择和文件页，保留原有目录、侧栏宽度与分屏。
