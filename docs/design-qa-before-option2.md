# OneAgent：文件单入口验收记录

日期：2026-10-13。最新要求为「相同功能只留一个入口」，用户进一步确认「保留两种布局，在同一入口互斥切换」。外观继续跟随系统。

## 当前交互

- 顶部「文件 ▾」是唯一可见的文件工作区入口。菜单包含「左右对照」与「终端下方」，当前打开的选项带勾。
- 「左右对照」显示整页双栏文件；「终端下方」显示终端与下方文件区。二者复用同一个文件视图及工作区，互斥显示。
- 顶部「终端」回到纯终端，同时收起任何文件布局；再次打开可选择任意布局。
- 删除右上角文件区开关、文件区展开/关闭按钮、终端分屏头部文件按钮和终端右键的文件管理入口。文件区不再重复显示「文件」标题。
- 共享上传/下载只保留一组。原有文件标签、多选、右键文件操作和传输逻辑继续复用；现有切换快捷键调用同一文件状态转换，不建立额外布局。
- 终端分屏菜单明确标为「终端布局」，与文件布局区分。

## 自动检查及安装

- `make test` 通过：旧布局迁移、序列化、两种布局严格互斥、原生最小尺寸和切换中的终端视图身份。
- `bash scripts/test-file-workspace-routing.sh` 通过：挂载真实 `RootView`，逐个切换两种布局及纯终端，辅助功能树中始终只有一个 `workspace.files` 入口；文件布局中恰好一个 `workspace.files.content`，纯终端中为零；旧开关/展开/关闭等重复控件均不存在。
- 同一测试验证当前本机/远程会话路由、切换布局后浏览目录与文件标签保留、终端会话身份不变，以及隐藏终端不抢文件输入焦点。使用临时 Home、隔离 UserDefaults、本地 SSH fixture 和独立进程/网络沙盒，不向用户远端传输数据。
